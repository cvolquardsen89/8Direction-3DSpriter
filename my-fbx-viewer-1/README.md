# My FBX Viewer

This project is a simple web-based viewer for FBX (Filmbox) files, allowing users to load and visualize 3D models in their browser.

## Table of Contents

- [Installation](#installation)
- [Usage](#usage)
- [Features](#features)
- [Contributing](#contributing)
- [License](#license)

## Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   cd my-fbx-viewer
   ```

2. Install the dependencies:
   ```
   npm install
   ```

## Usage

To start the application, open `src/index.html` in your web browser. You can load FBX files by using the provided interface.

## Features

- Load and display FBX files.
- Interactive 3D model viewer.
- Supports basic user interactions.
